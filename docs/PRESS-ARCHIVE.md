# Press archive
Research and implementation: 2026-11-08.

The /press page uses src/data/press.json. This is a growing, curated index, not a claim that every mention has been found. No external API or database is needed at runtime. Query parameters q, publication, year, kind, topic combine with AND; search terms match titles, descriptions, topics, and publications.

Each entry contains its source URL, publication, date (year only when exact date was not verified), a short editorial description, coverage type, and topics. Display titles may be shortened. Original journalism, company releases, and industry coverage are labeled. Nasdaq is credited as a CoinDesk republication. Do not count syndicated duplicates as independent reporting.
